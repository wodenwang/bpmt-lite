# v1.8.0 桌面现代化主题基础设计

## 版本定位

`v1.8.0` 是 `v2.0.0` 大版本的第一个 vertical slice。它只做 CSS-only 现代化主题基础，用一个可回滚的覆盖文件验证桌面 UI 风格提升是否可行。

## Product Design 决策

本版本由 Product Design 自主收敛为“中性工作台主题”方向。备选方向如下：

| 方向 | 说明 | 取舍 |
| --- | --- | --- |
| 保守 jQuery UI 清理 | 只去掉强拟物渐变和旧边框，几乎不改变密度。 | 风险最低，但视觉提升不明显。 |
| 中性工作台主题 | 浅灰页面背景、白色工作区、沉稳蓝主色、4px 到 6px 圆角、轻边框和明确 hover/focus。 | 推荐方向，现代化收益和旧控件兼容性平衡最好。 |
| 品牌强化主题 | 更明显的蓝色模块导航和更强阴影层级。 | 视觉更醒目，但容易干扰密集后台任务。 |

最终选择“中性工作台主题”。本方向适合系统管理员、业务管理员和外部集成开发者的高频后台工作，不做营销化视觉、不做大面积渐变、不降低信息密度。

## 目标

- 新增现代化桌面主题覆盖层。
- 不改业务 JSP。
- 不改 JavaScript 初始化逻辑。
- 不改低代码控件输出。
- 通过少量关键页面验证覆盖范围和风险。

## 非目标

- 不改移动端 H5。
- 不替换 icon 资源。
- 不改菜单结构。
- 不改表单布局协议。
- 不做所有页面逐项 polish。

引入位置：

```jsp

<link href="${_cp}/css/bpmt-modern.css" rel="stylesheet">
```

回滚方式：删除或注释 `bpmt-modern.css` 引入。

## 主题 token

在 `bpmt-modern.css` 顶部声明注释化 token，不依赖 CSS variables，避免旧浏览器兼容风险：

```css
/*
 * Surface: #f6f8fb
 * Panel: #ffffff
 * Border: #d9e2ec
 * Text: #1f2937
 * Muted: #667085
 * Primary: #2563eb
 * Danger: #dc2626
 * Success: #16a34a
 */
```

如确认运行环境不需要旧 IE，可在后续版本升级为 `:root` CSS variables。

## 设计细则

### 登录页

- 保持原登录逻辑。
- 登录框居中，白色面板，轻边框或轻阴影。
- logo 区更清晰，表单控件 32px 高。
- 登录按钮使用主色。
- copyright 弱化，不抢主视觉。

### 主框架

- 页面背景改为浅灰。
- topbar 从渐变灰改为低对比信息条。
- header 和模块按钮保留位置，但去掉强拟物渐变。
- 左侧菜单面板白底、轻边框。
- 主内容 panel 白底。

### 列表页

- 表头浅灰背景。
- 数据行增加行高。
- hover 使用浅蓝或浅灰。
- 操作列按钮保留 icon-only。
- 分页按钮减弱拟物感。

### 弹窗

- 标题栏纯色或浅灰。
- 内容区增加 padding。
- 关闭按钮可见且不挤压标题。
- 底部按钮区与内容区有明确分隔。

## 验收标准

- 不引入 JavaScript 错误。
- 登录、跳转、菜单点击、列表查询、弹窗打开关闭正常。
- 关键页面截图显示整体风格明显现代化。
- 回滚只需移除 `bpmt-modern.css` 引入。
- Maven 编译通过。
- API 文档和 OpenAPI 只更新版本元数据，不新增 endpoint。

```text
为 bpmt-lite 桌面后台生成 3 个现代化视觉方向。保留现有 topbar + 横向模块按钮 + 左侧树菜单 + 主内容区结构，不考虑移动端，不重写控件。风格应是安静、专业、低饱和、适合后台工作台的 CSS-only 皮肤。
```
