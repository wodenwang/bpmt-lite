## Step 0 范围挑战

### 现有代码已经覆盖什么

- 弹框：已有 `bpmt-modern.css` 覆盖 `.ui-dialog`、`.ui-dialog-titlebar-close` 和 `.ui-widget-overlay`，但缺少明确 `z-index` 阶梯，关闭按钮仍是 `28 x 28`。
- 空状态：`Core.initAfter(zone)` 已统一调用 `Core.applyEmptyTableState(zone)`，但 `ws-core-ext.js:150` 命中旧 `.bpmt-empty-table-row` 后直接返回，导致空状态不会随新查询结果移除。
- zTree：`bpmt-modern.css` 已有全站 `.ztree` 基础规则和 `#frame-menu-panel` 局部规则，但当前行高是 `26px`，且菜单和非菜单规则重复。
- 壳层：`frame_new/frame.jsp` 已有清晰挂点：`.tc-top-wrap`、`.tc-logo-wrap`、`.tc-tab-bar`、`.tc-slider-bar`、`.tc-container`；`frame_new/css/main.css` 是旧布局源，`bpmt-modern.css` 是更适合落地的覆盖层。

### 最小变更集

- `platform/src/main/webapp/css/bpmt-modern.css`
- `platform/src/main/webapp/js/ws-core-ext.js`
- 必要时少量调整 `platform/src/main/webapp/xhtml/frame_new/frame.jsp` 的语义 class。
- 文档：`docs/release-v1.9.0.md`、README/AGENTS 版本线、QA 证据。

不建议首轮改动：

- 不重写 `frame_new/menu.jsp` 的 zTree 初始化。
- 不替换 jQuery UI dialog 或 zTree。
- 不进入 H5。
- 不改 OAuth/API/数据库。

## 架构评审

### 目标态结构

```text
browser
  |
  v
frame_new/frame.jsp
  |-- .tc-top-wrap       top user actions
  |-- .tc-logo-wrap      brand area
  |-- .tc-tab-bar        domain tabs
  |-- .tc-slider-bar     zTree menu host
  '-- .tc-container      ajax main-zone

bpmt-modern.css
  |-- layer ladder       overlay/dialog always above shell/buttons
  |-- dialog component   close/titlebar button sizes
  |-- zTree base rules   stable row/a/icon box model
  '-- shell grid         visual grouping and alignment

ws-core-ext.js
  '-- Core.initAfter -> Core.applyEmptyTableState
      |-- current table has data row -> remove empty row
      '-- current table has no data  -> insert empty row
```

### 工程决策

| 决策 | 采用 | 理由 |
| --- | --- | --- |
| 全局 layer ladder，而不是逐个按钮降级 | 是 | 弹框遮罩问题是层级系统问题，逐个按钮修会复发 |
| 修 `Core.applyEmptyTableState`，而不是页面局部清理 | 是 | 空状态由所有旧列表共享，通用生命周期修复覆盖查询、分页、排序 |
| 全站 `.ztree` 基础尺寸 + 菜单局部颜色覆盖 | 是 | 非菜单 zTree 是本次明确范围，不能只修 `#frame-menu-panel` |
| CSS 覆盖层优先，JSP 只补语义 class | 是 | 最小化对旧 JSP、权限和 Ajax 刷新区的影响 |

## 代码质量评审

### P0：空状态逻辑必须移除旧行后再判断

证据：`ws-core-ext.js:150-152`

```javascript
if ($('.bpmt-empty-table-row', $table).size() > 0) {
	return;
}
```

处理方式：

- 将当前表格直接子层级下的 `.bpmt-empty-table-row` 缓存为 `$emptyRows`。
- 计算数据行时继续排除嵌套表格、表头行和空状态行。
- `hasDataRow == true` 时删除 `$emptyRows`。
- `hasDataRow == false` 且 `$emptyRows.size() > 0` 时保留现有空状态，不重复插入。

### P0：弹框层级必须比 shell 和插件按钮明确更高

证据：`frame.css` 中 `.frame.topbar` 和 `.frame.footer` 原始 `z-index: 99`；`bpmt-modern.css:377-380` 仅定义 overlay 背景和透明度，没有层级。

处理方式：

- 在 `bpmt-modern.css` 顶部注释定义 layer ladder。
- `.ui-widget-overlay` 设为高于 shell、chosen、zTree、表格按钮。
- `.ui-dialog` 设为高于 overlay。
- `#dialog-extend-fixed-container` 不得高于当前 modal overlay/dialog。

### P1：关闭按钮要覆盖 dialogExtend 注入按钮

证据：`jquery.dialogextend.min.js` 注入 `.ui-dialog-titlebar-buttonpane>a`，默认宽高 `19 x 18`；`bpmt-modern.css:358-363` 只覆盖 `.ui-dialog-titlebar-close` 为 `28 x 28`。

处理方式：

- 统一 `.ui-dialog .ui-dialog-titlebar-close` 和 `.ui-dialog .ui-dialog-titlebar-buttonpane > a` 的 `width/height`。
- 统一内部 `.ui-icon` 居中。
- hover/focus 只改颜色/背景，不改 padding、border、width、height。

### P1：zTree 规则要减少重复

证据：`bpmt-modern.css:952-970` 和 `1002-1020` 基本重复。

处理方式：

- 全站 `.ztree` 定义稳定盒模型。
- 菜单 `#frame-menu-panel` 只覆盖颜色、背景、文字截断宽度等视觉差异。
- 非菜单树不得被 `.tc-zTree` 的旧规则破坏 hover 尺寸。

## 性能与回滚

- CSS 改动不引入额外请求，不影响后端性能。
- `Core.applyEmptyTableState` 每次只遍历当前 zone 下的 `table.ws-table[form]`，复杂度与旧逻辑同量级。
- 若 shell 视觉收拢引发某些旧页面横向内容溢出，回滚优先撤销 shell grid 相关 CSS，不回滚空状态和弹框/zTree 缺陷修复。
- 发布后如发现局部 zTree 视觉异常，应通过局部选择器覆盖颜色，不回退全站稳定盒模型。
