# bpmt-lite v1.8.0 桌面现代化主题基础设计

## 版本定位

`v1.8.0` 是 `v2.0.0 Desktop UI Modernization` 的第一个 vertical slice。它以 CSS-only 覆盖层验证桌面后台现代化方向是否可行，不改 JavaScript 初始化、不改业务 JSP、不改低代码控件输出。

## Product Design brief

- 产品：`bpmt-lite` 遗留 BPMT 低代码后台。
- 用户：系统管理员、业务管理员、外部集成开发者。
- 目标：让桌面端从旧 jQuery UI 拟物皮肤升级为安静、专业、密度适中的现代后台工作台。
- 视觉来源：现有 BPMT 页面结构、`docs/v2.0.0/*` 规划、登录页、主框架、第三方系统列表、AI 接入提示词弹窗。
- 交互级别：全功能保留，主题层只改变视觉，不改变行为。

## 设计方向

Product Design 对比三个方向后选择“中性工作台主题”：

| 方向 | 结论 |
| --- | --- |
| 保守 jQuery UI 清理 | 兼容性最好，但现代化收益不足。 |
| 中性工作台主题 | 推荐，浅灰背景、白色工作区、沉稳蓝主色、轻边框、清晰 hover/focus，适合后台任务。 |
| 品牌强化主题 | 视觉更强，但容易干扰密集表格、配置和弹窗任务。 |

## 范围

- 新增 `platform/src/main/webapp/css/bpmt-modern.css`。
- 在 `platform/src/main/webapp/include/html_include.jsp` 的深浅主题 CSS 后引入 `bpmt-modern.css`。
- 覆盖基础字体、页面背景、表单控件、按钮、表格、panel、bar、message、tabs、dialog、zTree、chosen 和登录页基础样式。
- 更新 `README.md`、`AGENTS.md`、`docs/release-v1.8.0.md`、`docs/v2.0.0/*`、`docs/v1.8.0/*`。
- Maven 项目版本、默认镜像 tag、安装脚本默认 ref 更新到 `1.8.0` / `v1.8.0`。
- OpenAPI 只更新 `info.title`、`info.version` 和版本说明，不新增或删除 endpoint。

## 非范围

- 不改移动端 H5。
- 不改业务 JSP DOM 结构。
- 不改 JavaScript 生命周期。
- 不改菜单、权限、OAuth、API 鉴权、动态表、报表或流程业务逻辑。
- 不升级 Java、Tomcat、Maven、MariaDB、jQuery、jQuery UI、zTree 或 chosen。
- 不替换 icon 资源。

## 视觉规范

- 背景：页面浅灰，工作区白底。
- 主色：沉稳蓝，只用于主按钮、当前态和重点交互。
- 文本：系统字体栈，默认 13px，后台密度不降到营销页尺度。
- 形态：4px 到 6px 圆角，轻边框，少量阴影。
- 表格：表头浅灰、行 hover 清晰、行高略提升。
- 弹窗：白色标题栏、内容 padding、底部按钮区分隔、遮罩透明度降低干扰。
- 登录页：保留原逻辑，登录 panel 更清晰，输入框和按钮高度提升到 30px 左右。

## 回滚

优先回滚 `platform/src/main/webapp/include/html_include.jsp` 中的：

```jsp
<link href="${_cp}/css/bpmt-modern.css" rel="stylesheet">
```

如果只需局部修复，优先改 `bpmt-modern.css`，不要改业务 JSP 或旧控件初始化。

## 验收

- `mvn -s settings.local.xml -DskipTests compile` 通过。
- 本地 Web/API 服务可启动。
- `/`、`/ueditor/`、`/api/docs/`、`/api/openapi.json` 返回正常。
- 桌面 1440x900 截图覆盖登录页、首页、功能设置首页、第三方系统列表、AI 接入提示词弹窗。
- Product Design 自审确认无关键视觉阻塞：文本不重叠、按钮不换行、弹窗不溢出、表格可扫描、旧控件仍可操作。
