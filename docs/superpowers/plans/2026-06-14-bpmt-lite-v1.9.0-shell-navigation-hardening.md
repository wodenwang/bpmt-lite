# bpmt-lite v1.9.0 Shell Navigation Hardening Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 修复 `v1.9.0` 已知桌面后台全局缺陷，并把 `frame_new` 桌面壳层收拢成对齐的导航侧栏和工作区。

**Architecture:** 以现有 `frame_new` JSP、zTree、jQuery UI dialog 和旧表格输出为边界，不替换控件库。优先在 `bpmt-modern.css` 做全局视觉与层级覆盖，在 `ws-core-ext.js` 修复空状态生命周期，必要时只给 JSP 补语义 class。

**Tech Stack:** Java 8、Maven 3、Tomcat 7、JSP、jQuery、jQuery UI、zTree、Playwright 手动/自动浏览器验证。

## Task 2: Empty Table State Lifecycle

**Files:**
- Modify: `platform/src/main/webapp/js/ws-core-ext.js:146-200`
- Test: browser query transition empty -> non-empty

- [x] **Step 1: Replace the early return with current-table empty row tracking**

In `Core.applyEmptyTableState`, replace:

```javascript
if ($('.bpmt-empty-table-row', $table).size() > 0) {
	return;
}
```

with:

```javascript
var $emptyRows = $('.bpmt-empty-table-row', $table).filter(function() {
	return $(this).parents('table:first')[0] == $table[0];
});
```

- [x] **Step 2: Remove stale empty state when data exists**

Replace:

```javascript
if (hasDataRow) {
	return;
}
```

with:

```javascript
if (hasDataRow) {
	$emptyRows.remove();
	return;
}
if ($emptyRows.size() > 0) {
	return;
}
```
