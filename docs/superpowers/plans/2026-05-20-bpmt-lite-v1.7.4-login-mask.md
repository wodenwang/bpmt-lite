# bpmt-lite v1.7.4 登录后灰色蒙版修复计划

## 目标

`v1.7.4` 是基于 `v1.7.3` 的小补丁版本，只修复登录后偶发出现灰色底蒙版的问题，不新增业务功能、不改变 API 能力、不改变数据库初始化结构或 Docker Compose 拓扑。

## 根因

整页模板在加载结束时只通过 CSS 隐藏 `#loading`，没有统一清理 jQuery UI / AmazeUI modal 遮罩。浏览器在登录跳转、回退缓存恢复或快速重登时，如果 DOM 中残留了没有活动弹窗对应的 `.ui-widget-overlay`、`.am-dimmer` 或加载 modal，就会在登录后的首页上留下灰色蒙版。

## 修复范围

- `platform/src/main/webapp/js/ws-core.js`
  - 新增 `Core.clearPageMask()`，清理整页加载提示和孤儿 modal 遮罩。
  - 在根页面 `Core.init()`、`window load` 和 `pageshow` 时执行清理。
  - 保留正常已打开弹窗的遮罩，不移除活动 dialog 对应的 overlay。
- `platform/src/main/webapp/include/html_bottom.jsp`
  - 整页渲染结束时优先调用 `Core.clearPageMask()`，兜底保留原 `#loading` 隐藏逻辑。
- `platform/src/test/java/com/riversoft/module/frame/LoginMaskCleanupTest.java`
  - 增加静态回归测试，防止全局清理逻辑被移除。
