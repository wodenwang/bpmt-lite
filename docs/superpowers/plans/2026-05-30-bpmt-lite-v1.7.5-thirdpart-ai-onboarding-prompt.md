# v1.7.5 Thirdpart AI Onboarding Prompt Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在“第三方系统”列表页增加“AI 接入提示词”按钮，弹框展示一段可复制到 Codex 或 Claude Code 空白项目中的提示词，用于初始化第三方项目的 `AGENTS.md` 或 `CLAUDE.md`，并明确 BPMT OAuth 与 API 接入配置。

**Architecture:** 功能仍放在 `bpmt-web/platform` 的第三方系统管理模块，不新增数据库字段，不改变 OAuth、HMAC API、Docker 拓扑或权限模型。列表页按钮从当前 `CM_THIRDPART` 记录读取 `clientId`、`redirectUris`、`homeUrl`、`thirdpartKey`、`thirdpartName`，弹框内允许管理员临时填写明文 `clientSecret`、`BPMT_API_APP_KEY`、`BPMT_API_APP_SECRET` 后生成提示词；这些明文只存在浏览器内存，不提交、不落库、不写日志。

**Tech Stack:** Java 8、JSP/JSTL、现有 BPMT `Core.fn`/`Actions.includePage` 页面模式、JUnit4、Maven `settings.local.xml`。

---

## 版本边界

建议版本号：`v1.7.5`。

本版本是后台管理体验补丁，不新增外部协议能力：

- 增加列表页操作按钮：“AI 接入提示词”。
- 点击后弹出提示词生成框。
- 提示词面向空白第三方项目，要求 Codex/Claude Code 初始化 `AGENTS.md` 或 `CLAUDE.md`。
- 提示词说明第三方系统后续组织用户与登录统一走 BPMT OAuth Authorization Code。
- 提示词说明如需调用 BPMT 业务 API，则使用现有 `X-BPMT-App-Key`、`X-BPMT-Timestamp`、`X-BPMT-Nonce`、`X-BPMT-Signature` HMAC 规则。
- 不从数据库读取或展示 `CLIENT_SECRET_HASH`。
- 不把 `clientSecret`、`apiSecret` 写入服务端请求、日志、数据库或页面 HTML 初始渲染。

不纳入本版本：

- 不生成完整第三方 demo 项目。
- 不新增 OAuth endpoint、OIDC、refresh token、SSO logout。
- 不新增每个第三方系统独立 API key/secret 数据模型。
- 不改变 `bpmt-api` HMAC 认证规则。
- 不把全局 `BPMT_API_APP_SECRET` 从 API 容器暴露给 Web 容器。
- 不自动创建第三方项目文件。

- [ ] **Step 3: 增加前端生成逻辑**

在现有 `$(function(){ ... })` 中增加：

```javascript
$('button[name=aiPrompt]', $zone).click(function() {
    var $button = $(this);
    var data = {
        thirdpartKey: $button.val(),
        thirdpartName: $button.attr('data-thirdpart-name') || '',
        clientId: $button.attr('data-client-id') || '',
        redirectUris: $button.attr('data-redirect-uris') || '',
        homeUrl: $button.attr('data-home-url') || '',
        clientSecret: 'CLIENT_SECRET_PLACEHOLDER',
        apiAppKey: 'BPMT_API_APP_KEY',
        apiAppSecret: 'BPMT_API_APP_SECRET'
    };
    var $dialog = $('#${_zone}_bpmt_ai_prompt_dialog');
    renderAiPrompt($dialog, data);
    $dialog.dialog({ title: 'AI 接入提示词', width: 760, modal: true });
});
```

再增加 `renderAiPrompt` 和 `buildAiPrompt`。提示词必须包含：

- 目标文件：优先更新现有 `AGENTS.md` 或 `CLAUDE.md`；两者都不存在时按运行工具创建对应文件。
- BPMT 基础地址。
- OAuth authorize/token/userinfo 端点。
- `client_id`。
- `client_secret` 明文占位或管理员临时填写值。
- `redirect_uri` 白名单。
- `state` 校验要求。
- token/userinfo 使用方式。
- BPMT API HMAC 请求头与 canonical path 规则。
- 组织用户与登录边界：第三方系统不维护独立 BPMT 用户密码，登录统一跳 BPMT OAuth。
