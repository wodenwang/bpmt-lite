# bpmt-lite v1.8.0 桌面后台清晰度基线实施计划

> 本计划替代 `2026-06-11-bpmt-lite-v1.8.0-modern-theme-foundation.md`。旧计划保留为失败方向记录，不再作为实现依据。

## Goal

把 `v1.8.0` 从 CSS-only 现代主题改为桌面后台清晰度基线。第一阶段只做三条代表路径，证明新方向能让用户任务更清楚，而不是让全站看起来更浅、更白。

## Design brief

- 产品：`bpmt-lite` 桌面后台。
- 目标用户：系统管理员、业务管理员、外部集成开发者。
- 代表路径：登录后首页、第三方系统列表、AI 接入提示词弹窗。
- 视觉来源：当前本地截图、旧后台结构、现有 JSP/jQuery UI/zTree/chosen 控件。
- 交互要求：真实系统可运行，不做纯静态演示。
- 约束：不升级技术栈，不改业务逻辑，不改权限/菜单/表单提交模型。

## Architecture

本计划不默认使用全局现代主题覆盖层。实现分为三类变更：

1. 文档和设计证据：重新锁定范围、目标态和验收。
2. 小范围 DOM 语义补充：页面标题、说明、空状态、按钮说明、复制反馈。
3. 小范围 CSS：只服务代表路径的清晰度，不做全系统皮肤。

`bpmt-modern.css` 的处理方式已决策为保留文件名、收窄定位：继续作为最后加载的桌面覆盖层，但内容从“全局现代主题”转为“桌面后台清晰度基线”。这样不增加新的全局引入点，也保留单文件回滚能力。

- 首页状态不再只有旧 loading 条。
- 实现 diff 不包含无关业务逻辑。
- 旧 CSS-only 现代主题不再作为发布目标。
